# Свои модели без своего кода

Три вида своей модели, которым движок автора не нужен. Модель на движке автора ведёт
skill `looma-engine`. Полная справка:
[own-models.md](https://github.com/LoomaFloat/looma-kit/blob/main/docs/own-models.md).

Имя модели: `автор/имя`. Сначала модель видит и зовёт только автор; другим она доступна
после `looma model publish` и проверки площадки. Опубликованную модель зовут по её
имени ключом любой учётной записи площадки (ключ выпускается в кабинете, раздел
«Подключение») и из `gpu:` сервисов других авторов: так модель встраивают сторонние
разработчики.

## Настройка поверх модели сети

Своих видеокарт нет: настройка работает на репликах модели сети.

```bash
looma models                                   # выбрать основу
looma model add tone --base Qwen3.8-Flash-Next-NVFP4 --preset preset.json
looma call anna/tone "Проверка"                # пробный вызов
```

`preset.json` у текстовой модели: `system` (системный промпт), `template` (шаблон
сообщения с полями `{имя}`), `inputs` (поля входа: имя, подпись, тип), `params`
(температура, предел токенов). У изображений и видео: `prompt`, `inputs`, `params`.
Вызывают настройку как обычную модель, обычными сообщениями (`messages`, свободный
текст пользователя), а со своим входом полями: `looma.chat("anna/tone",
input={"text": "…"})`. Качество проверяй пробными вызовами (`looma call anna/tone "…"`)
на тех же примерах, на которых работал прежний поставщик, и показывай ответы автору.

Когда: вся «модель» сводится к промпту, шаблону и параметрам. Публикуется, как модель:
другие авторы ставят её в `gpu:` своих сервисов.

## Адаптер LoRA

```bash
looma model adapters                           # адаптеры проекта
looma model add legal --base Qwen/Qwen3-8B --adapter legal
```

Своя реплика: модель с вплавленным адаптером. Основа должна быть в каталоге.

## Свои веса на движке площадки

```bash
looma model check --repo anna/qwen-legal       # формат, размер, встанет ли в сети
looma model add qwen-legal --repo anna/qwen-legal
looma model set qwen-legal --always            # держать реплику всегда (иначе спит)
looma model set qwen-legal --price in=5 --price out=15   # рубли за 1M токенов
```

Веса: открытый репозиторий HuggingFace, safetensors, без своего кода модели. Движки
площадки: `torch` (по умолчанию; большая модель делится на части по нескольким
машинам), `vllm`, `diffusion` (изображения и видео), `embed` (векторы и ре-ранк).
Параметры движка: `--set имя=значение`, список полей даёт кабинет («Модели» → «Своя
модель»).

## Общее для своих моделей

| Что | Команда |
|---|---|
| описание | `looma model set имя --summary "…"` |
| цена | `--price call=…` (вызов со своим API), `in=…`, `out=…` (1M токенов), `image=…`, `second=…` (секунда видео); `--free` убирает |
| реплика всегда или сон | `--always`, `--sleep` |
| только свои узлы | `--own`; снова в сеть: `--network` |
| лог реплик | `looma model logs имя` |
| публикация | `looma model publish имя` (по просьбе автора), `unpublish` |
| удаление | `looma model delete имя --yes` (необратимо, по просьбе автора) |

Время карт под свои реплики идёт автору в расходы; на своих узлах не записывается. Из
сервиса модель зовут, объявив её в `gpu:` под полным именем: `chat: { model: anna/tone }`.
