# {{name}}: чат-ассистент

Страница с чатом: ответ большой модели печатается по мере генерации.

```bash
looma deploy && looma open --env staging
looma secrets set ASSISTANT_SYSTEM="Ты — вежливый юрист. Отвечай коротко."
looma promote
```

Для ИИ-агентов есть инструмент MCP `ask` (`POST /api/ask`, ответ целиком). Когда
карточка пройдёт модерацию после `looma publish`, клиенты смогут подключить его к Claude
или Cursor со страницы сервиса в каталоге. Ответы клиентам каталога отмечаются событием
`answer`; цену ответа в рублях задаёт поле `price` в `events`.

Модель указана в `looma.yaml` (`gpu.chat`) и в `ASSISTANT_MODEL`. Локально: `looma dev`
и http://127.0.0.1:8080. Модель вызывается dev-токеном сервиса с дневной квотой,
характер задаёт строка `ASSISTANT_SYSTEM=…` в `.env`.
