# {{name}}

Сервис на Looma Float.

```bash
looma deploy          # собрать релиз, он встанет на staging
looma status          # адреса и процессы
looma logs -f         # лог веб-процесса
looma promote         # staging → prod
```

Локально: `looma dev` и http://127.0.0.1:8080, окружение как на площадке.
