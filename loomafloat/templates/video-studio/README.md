# {{name}} — видеостудия

Описание словами → ролик на 5 секунд (MiniMax-H3, считается несколько минут).
Галерея — в бакете приложения: у каждого клиента маркетплейса своя.

```bash
looma deploy && looma open --env staging
looma promote
```

Ролик считает платформа: процесс помнит номер задания и забирает готовый ролик
при следующем заходе — сон процесса ролик не теряет. Готовый ролик клиента
отмечается событием `video`. Ролик дорогой — `access: clients` в looma.yaml
откроет студию только клиентам маркетплейса.

Локально: `pip install -r requirements.txt && looma dev` — бакет поднимется в Docker;
без Docker — `looma dev --no-data`, ролики ложатся в `./videos`.
