# {{name}}: видеостудия

Ролик на 5 секунд по описанию словами (MiniMax-H3, считается несколько минут).
Галерея лежит в бакете сервиса, у каждого клиента каталога своя.

```bash
looma deploy && looma open --env staging
looma promote
```

Ролик считает площадка. Процесс помнит номер задания и забирает готовый ролик при
следующем заходе, поэтому сон процесса ролик не теряет. Готовый ролик клиента
отмечается событием `video`; цену ролика в рублях задаёт поле `price` в `events`.
Ролик занимает минуты работы модели: `access: clients` в looma.yaml откроет студию
только клиентам каталога.

Локально: `pip install -r requirements.txt && looma dev`, бакет поднимется в Docker.
Без Docker запустите `looma dev --no-data`, ролики будут ложиться в `./videos`.
