# {{name}}: Telegram-бот с генерацией

- текст → изображение (Qwen-Image-2.1);
- фото с подписью → правка фото по подписи;
- `/video <описание>` → ролик 5 секунд (MiniMax-H3, считается несколько минут).

```bash
looma deploy
looma secrets set TELEGRAM_BOT_TOKEN=123456:ABC…   # токен от @BotFather
looma promote          # вебхук на площадку бот поставит сам
```

Обновления идут через площадку (`channels.telegram` в looma.yaml): она сверяет секрет
Telegram и называет боту отправителя (`X-Looma-Client`). Изображения и ролики
записываются на него, готовые отмечаются событиями `picture` и `video`. Впишите в
`channels.telegram` своего бота, `bot: "@ИмяБота"`, и на карточке в каталоге появится
ссылка на него.

Вебхук ставится только на prod (`LOOMA_ENVIRONMENT=prod`): на staging тот же токен
перехватил бы сообщения. Для staging заведите второго бота и поставьте секрет
`BOT_WEBHOOK_ENV=staging`. Такой бот примет обновления сам, на свой адрес, и клиентов
площадка ему не называет. Или проверяйте на prod.

`looma dev` запустит бота у вас (токен задайте строкой `TELEGRAM_BOT_TOKEN=…` в `.env`),
но сообщений он не получит: Telegram шлёт вебхук только на публичный адрес.
