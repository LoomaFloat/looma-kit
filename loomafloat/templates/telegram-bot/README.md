# {{name}} — Telegram-бот с генерацией

- текст → картинка (Qwen-Image-2.1);
- фото с подписью → правка фото по подписи;
- `/video <описание>` → ролик 5 секунд (MiniMax-H3, минуты).

```bash
looma deploy
looma secrets set TELEGRAM_BOT_TOKEN=123456:ABC…   # токен от @BotFather
looma promote          # вебхук бот поставит сам — на платформу
```

Обновления идут через платформу (`channels.telegram` в looma.yaml): она сверяет
секрет Telegram и называет боту отправителя (`X-Looma-Client`) — картинки и ролики
записываются на него, готовые отмечаются событиями `picture` и `video`. Впишите в
`channels.telegram` своего `bot: "@ИмяБота"` — в карточке маркетплейса появится
ссылка на него.

Вебхук ставится только на prod (`LOOMA_ENVIRONMENT=prod`): у staging тот же
токен перехватил бы сообщения. Для staging заведите второго бота и поставьте
`BOT_WEBHOOK_ENV=staging` секретом — он примет обновления сам, на свой адрес
(клиентов платформа ему не называет), — или проверяйте на prod.

`looma dev` запустит бота у вас (токен — строкой `TELEGRAM_BOT_TOKEN=…` в `.env`), но
сообщений он не получит: Telegram шлёт вебхук только на публичный адрес.
