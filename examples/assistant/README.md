# Ассистент

Код сервиса «Ассистент» из каталога Looma Float. Это чат с большой моделью: ответ
печатается по мере генерации, разговор хранится в браузере клиента. Сервис собран из
шаблона `assistant` (`looma init -t assistant`).

## Что умеет

- Страница с чатом. История разговора приходит на сервер целиком с каждым вопросом,
  поэтому процессу нечего помнить и сон без запросов разговор не теряет.
- Инструмент MCP `ask` для ИИ-агентов: вопрос приходит в `POST /api/ask`, в ответе
  текст целиком. Клиент подключает его к Claude или Cursor со страницы сервиса в каталоге.
- API по ключу клиента (канал `api`).
- Только для клиентов каталога (`access: clients`). Вызовы модели записываются на
  клиента, каждый ответ отмечается событием `answer`.

## Модели

| Шаг в `gpu` | Модель | Зачем |
|---|---|---|
| `chat` | `Qwen3.8-Flash-Next-NVFP4` | ответ в чате и в инструменте `ask` |

Другую модель укажите в `gpu.chat` и в секрете `ASSISTANT_MODEL` (или в константе
`MODEL` в `app.py`). Сервис вызывает только модели из раздела `gpu`, остальные отвечают
`403`. Имена моделей показывает `looma models`.

## События

| Событие | Когда отмечается |
|---|---|
| `answer` | готов ответ клиенту каталога, в чате или в инструменте `ask` |

## Секреты

Оба секрета необязательны.

| Секрет | Что задаёт |
|---|---|
| `ASSISTANT_SYSTEM` | характер ассистента: системную подсказку модели |
| `ASSISTANT_MODEL` | модель вместо `Qwen3.8-Flash-Next-NVFP4`; она должна быть и в `gpu` |

```bash
looma secrets set ASSISTANT_SYSTEM="Ты вежливый юрист. Отвечай коротко."
looma restart web
```

Процесс видит новое значение после перезапуска.

## Файлы

```
looma.yaml     манифест: процесс, модель, событие, каналы, секреты, карточка
app.py         HTTP-сервер: страница, POST /api/chat (ответ потоком), POST /api/ask (MCP)
icon.png       иконка карточки
.loomaignore   что не едет в релиз
```

Других зависимостей нет: сервер на `http.server`, модель вызывает SDK `loomafloat`.

## Подготовка

1. Установите CLI:

   ```bash
   uv tool install "git+https://github.com/LoomaFloat/looma-kit"
   ```

2. Войдите командой `looma login`. Откроется браузер на странице
   `console.loomafloat.ru/device`: подтвердите вход в кабинете автора, ключ сохранится
   сам.
3. Задайте своё имя в строке `name:` файла `looma.yaml`. Имена на Looma Float
   уникальны, а `looma-assistant` занято этим сервисом в каталоге. `looma dev` и
   `looma deploy` заводят сервис под именем из манифеста, из него же получаются адреса.

## Запустить у себя

```bash
looma sdk      # копия SDK в папке loomafloat/
looma dev      # http://127.0.0.1:8080
```

Модели настоящие: `looma dev` вызывает их dev-токеном сервиса, не больше 200 вызовов в
сутки. Секреты берутся из файла `.env` в папке сервиса, например строка
`ASSISTANT_SYSTEM=…`. Клиента каталога у себя нет: все запросы идут от одного посетителя
без входа, и событие `answer` не отмечается.

## Выкатить

```bash
looma validate               # проверка манифеста и проекта без релиза
looma deploy                 # релиз на staging
looma check --env staging    # запрос к сервису: код ответа, время, начало ответа
looma promote                # перевести релиз со staging на prod
```

Если копии SDK в проекте нет, `looma deploy` положит её сам. `looma check` доходит до
процесса и при `access: clients`. Открыть staging в браузере: `looma open --env staging`,
витрина попросит войти. Логи: `looma logs --env staging`.

## Опубликовать

```bash
looma publish    # карточка и цены уходят на модерацию
looma listing    # состояние карточки и решение модерации
```

`looma publish` берёт раздел `listing` и цены из `events` в `looma.yaml` релиза на prod.
Решение модерации видно в кабинете автора и в `looma listing`. После одобрения карточка
появляется в каталоге.

## Цена

В примере цены нет, событие `answer` бесплатное. Чтобы брать плату за ответ, добавьте
событию поле `price`:

```yaml
events:
  - { name: answer, title: Ответ, price: 2 }
```

`price` задаёт цену за один ответ в рублях, можно с копейками; число здесь только пример. Новая цена
действует после модерации, а не после релиза: выкатите правку на prod (`looma deploy`,
`looma promote`), выполните `looma publish` и дождитесь одобрения.

Подробно: [Быстрый старт](https://docs.loomafloat.ru/authors/quickstart/),
[Клиенты и цены](https://docs.loomafloat.ru/authors/prices/).
