# Куратор рецептов

Учебный сервис входа через Looma с правами. С согласия человека он заводит черновик
рецепта в его каталоге Looma Float: настройку поверх модели сети. Из черновика человек
потом делает свою модель в кабинете автора.

## Как это устроено

1. В `looma.yaml` сервис объявляет право `account: [catalog.draft]`.
2. Человек открывает сервис. Ключа человека в запросе нет (`person_of(headers)` даёт
   `None`), поэтому страница ведёт его на `/.looma/consent?next=/`. Этот адрес держит
   шлюз площадки, а не сервис.
3. Площадка показывает страницу согласия: «Сервис сможет заводить и править черновики
   в вашем каталоге». Человек нажимает «Разрешить» и возвращается в сервис.
4. Дальше в каждом его запросе к сервису есть заголовок `X-Looma-Account-Key`: ключ на
   десять минут. Сервис зовёт API площадки своим токеном вместе с этим ключом:

   ```python
   from loomafloat import Looma, person_of

   looma = Looma()
   made = looma.for_person(person_of(headers)).recipes.add(
       "contracts", base="Qwen3.8-Flash-Next-NVFP4", preset={"system": "Ты помогаешь юристу…"})
   ```

5. Черновик лежит в каталоге человека с пометкой «сделано сервисом Куратор рецептов».
   Человек видит доступ в кабинете, раздел «Доступы сервисов», и может его отозвать:
   следующий запрос сервиса придёт уже без ключа.

## Что ключ умеет

С правом `catalog.draft` ключ заводит и правит черновики весов, рецептов и моделей.
С правом `catalog.publish` ещё открывает записи другим авторам и отправляет их на
публикацию. Удалять записи, задавать цены, держать реплики постоянно, вызывать модели,
выпускать ключи и читать почту ключ не может. Подробнее: [Вход через Looma с
правами](../../skills/looma-port/references/manifest.md#account).

## Запуск

```bash
looma deploy              # релиз на staging
looma check --env staging # страница отвечает
```

Проверять нужно на staging: ключ человека выдаёт шлюз площадки. У себя (`looma dev`)
шлюза нет, страница покажет кнопку «Разрешить доступ», а переход по ней не сработает.

## Секреты

| Секрет | Что задаёт |
|---|---|
| `CURATOR_BASE` | модель-основу рецепта вместо `Qwen3.8-Flash-Next-NVFP4`; она должна быть в каталоге |
