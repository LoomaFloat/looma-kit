# Видеостудия

Код сервиса «Видеостудия» из каталога Looma Float. Студия снимает ролик на 5 секунд по
описанию словами и хранит ролики в галерее. Сервис собран из шаблона `video-studio`
(`looma init -t video-studio`).

## Что умеет

- Ролик по описанию сцены, например «рыжая лиса бежит по снегу». Съёмка занимает
  несколько минут, страницу можно закрыть.
- Ролик считает площадка заданием `POST /v1/videos`. Процесс помнит только номер задания
  и забирает готовый ролик в бакет при следующем заходе, поэтому сон процесса ролик не
  теряет.
- Галерея в бакете сервиса (`data.bucket`). У каждого клиента каталога своя галерея:
  чужие ролики не видны.
- Ролики смотрятся прямо на странице: сервер отдаёт их с поддержкой `Range`, без неё
  Safari не играет видео.
- Только для клиентов каталога (`access: clients`): ролик занимает минуты работы модели.

## Модели

| Шаг в `gpu` | Модель | Зачем |
|---|---|---|
| `video` | `MiniMax-H3` | ролик по описанию, качество `fast` |

Модель и качество можно поменять переменными `STUDIO_VIDEO_MODEL` и
`STUDIO_VIDEO_QUALITY` или константами в начале `studio.py`. Новая модель должна быть и в
`gpu.video`: сервис вызывает только модели из раздела `gpu`, остальные отвечают `403`.
Имена моделей показывает `looma models`.

## События

| Событие | Когда отмечается |
|---|---|
| `video` | ролик клиента каталога готов и лежит в бакете |

Событие отмечается с номером ролика (`id`), поэтому повторный заход не запишет его дважды.

## API

```
GET  /                страница
POST /api/videos      {"prompt"} → {"id"}: задание, ролик считается несколько минут
GET  /api/videos      мои ролики, готовые и в работе
GET  /video/<id>.mp4  сам ролик
```

## Файлы

```
looma.yaml         манифест: процесс, бакет, модель, событие, карточка
studio.py          HTTP-сервер: страница, задания на ролик, галерея
requirements.txt   boto3 для бакета

.loomaignore       что не едет в релиз: папка videos/ и логи
```

## Подготовка

1. Установите CLI:

   ```bash
   uv tool install "git+https://github.com/LoomaFloat/looma-kit"
   ```

2. Войдите командой `looma login`. Откроется браузер на странице
   `console.loomafloat.ru/device`: подтвердите вход в кабинете автора, ключ сохранится
   сам.
3. Задайте своё имя в строке `name:` файла `looma.yaml`. Имена на Looma Float
   уникальны, а `looma-video` занято этим сервисом в каталоге. `looma dev` и
   `looma deploy` заводят сервис под именем из манифеста, из него же получаются адреса.

## Запустить у себя

```bash
looma sdk                          # копия SDK в папке loomafloat/
pip install -r requirements.txt    # boto3 для бакета
looma dev                          # http://127.0.0.1:8080, бакет в Docker
```

Без Docker запустите `looma dev --no-data`: ролики будут ложиться в папку `./videos`.
С `looma dev --docker` процесс идёт в образе, собранном как на площадке, и ставить
зависимости не нужно.

Модели настоящие: `looma dev` вызывает их dev-токеном сервиса, не больше 200 вызовов в
сутки. Клиента каталога у себя нет: все запросы идут от одного посетителя без входа, и
событие `video` не отмечается.

## Выкатить

```bash
looma validate               # проверка манифеста и проекта без релиза
looma deploy                 # релиз на staging
looma check --env staging    # запрос к сервису: код ответа, время, начало ответа
looma promote                # перевести релиз со staging на prod
```

Если копии SDK в проекте нет, `looma deploy` положит её сам. `looma check` доходит до
процесса и при `access: clients`. Открыть staging в браузере: `looma open --env staging`,
витрина попросит войти. Логи: `looma logs --env staging`.

## Опубликовать

```bash
looma publish    # карточка и цены уходят на модерацию
looma listing    # состояние карточки и решение модерации
```

`looma publish` берёт раздел `listing` и цены из `events` в `looma.yaml` релиза на prod.
Решение модерации видно в кабинете автора и в `looma listing`. После одобрения карточка
появляется в каталоге.

## Цена

В примере цены нет, событие `video` бесплатное. Чтобы брать плату за ролик, добавьте
событию поле `price`:

```yaml
events:
  - { name: video, title: Ролик, price: 49 }
```

`price` задаёт цену за один ролик в рублях, можно с копейками; число здесь только пример. Новая цена
действует после модерации, а не после релиза: выкатите правку на prod (`looma deploy`,
`looma promote`), выполните `looma publish` и дождитесь одобрения.

Подробно: [Быстрый старт](https://docs.loomafloat.ru/authors/quickstart/),
[Клиенты и цены](https://docs.loomafloat.ru/authors/prices/).
