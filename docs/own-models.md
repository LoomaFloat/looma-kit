# Свои модели

Сервисы на Looma Float вызывают модели сети. Если готовой модели мало, автор добавляет
в каталог свою. Сначала её видит и вызывает только он. После проверки площадки модель
могут вызывать другие авторы, по цене, которую он назначил.

Своя модель бывает трёх видов.

| Вид | Что приносит автор | Свои реплики | Когда подходит |
|---|---|---|---|
| Свои веса | репозиторий весов на HuggingFace | да | своя или дообученная модель целиком |
| Модель с адаптером | адаптер LoRA к модели каталога | да | модель каталога, дообученная под задачу |
| Настройка | системный промпт, параметры, поля входа | нет | готовая модель каталога с закреплённым поведением |

Реплика означает копию модели, загруженную на видеокарты сети. Время видеокарт под
свои реплики записывается автору в расходы. У настройки своих реплик нет: её вызовы
считает модель, поверх которой она сделана.

Все действия есть в кабинете автора, в разделе «Модели», и в CLI: команда
`looma model`. ИИ-агент делает то же инструментами `looma_model_*`.

## Имя автора {#handle}

Модель автора называется `автор/модель`, например `anna/qwen-legal`. Первая часть
означает имя автора: от 3 до 32 знаков, латиница, цифры и дефис. Оно задаётся один раз,
перед первой моделью, и потом не меняется.

```sh
looma model name anna
```

## Свои веса {#weights}

Модель работает на движке площадки с вашими весами. Веса берутся из открытого
репозитория на HuggingFace и проверяются до запуска:

- формат safetensors;
- в репозитории нет своего кода модели (`auto_map` в `config.json`);
- размер не больше предела площадки, его показывает форма в кабинете автора.

```sh
looma model check --repo anna/qwen-legal        # веса и место в сети, ничего не запускает
looma model add qwen-legal --repo anna/qwen-legal --summary "Юридический ассистент"
```

Движок выбирает флаг `--engine` (по умолчанию `torch`), его параметры задаёт
`--set имя=значение`. Список движков и их полей показывает форма «Своя модель» в
кабинете автора.

По умолчанию модель спит без запросов. Первый вызов её будит, это занимает до
нескольких минут. С флагом `--always` одна реплика работает постоянно: модель отвечает
сразу, а время видеокарт идёт в расходы и без запросов. Поменять это позже:
`looma model set qwen-legal --always` или `--sleep`.

## Модель с адаптером {#adapter}

Адаптер LoRA получается при дообучении: это небольшой файл поправок к весам модели.
Он появляется в проекте после обучения или загружается готовыми файлами. Какие
адаптеры есть, показывает `looma model adapters`.

```sh
looma model add qwen-legal --base Qwen3.8-Flash-Next-NVFP4 --adapter legal
```

`--base` называет модель каталога с теми же весами, на которых обучен адаптер. От неё
берутся движок и его параметры. Адаптер встраивается в веса при загрузке, поэтому под
такую модель поднимаются свои реплики, как под свои веса.

## Настройка поверх модели {#preset}

Настройка закрепляет, как вызывать модель каталога: системный промпт, параметры и поля
входа. Она получает своё имя в каталоге и свою цену, но работает на репликах модели,
поверх которой сделана. Сто настроек поверх одной модели не занимают ни одной лишней
видеокарты.

Настройка описывается файлом JSON. Для текстовой модели:

```json
{
  "system": "Ты переводчик договоров. Сохраняй нумерацию пунктов.",
  "template": "Переведи на {language}:\n{text}",
  "inputs": [
    {"name": "text", "title": "Текст договора"},
    {"name": "language", "title": "Язык перевода", "type": "select",
     "options": ["английский", "китайский"], "default": "английский", "required": false}
  ],
  "params": {"temperature": 0.2, "max_tokens": 900}
}
```

| Поле | Что задаёт |
|---|---|
| `system` | системный промпт: модель получает его перед каждым запросом |
| `template` | шаблон запроса: поля входа подставляются по именам в фигурных скобках |
| `inputs` | поля входа: `name`, подпись `title`, вид `type` (`text`, `number`, `select`), `required`, `default`, для `select` список `options` |
| `params` | закреплённые параметры: `temperature`, `top_p`, `max_tokens`, `presence_penalty`, `frequency_penalty` |

Для модели изображений или видео вместо `system` и `template` задаётся `prompt`:
шаблон промпта, где `{prompt}` занимает промпт того, кто вызывает. В `params` идут
параметры задания, например `size`, `seconds`, `num_inference_steps`.

```json
{
  "prompt": "Портрет в технике масляной живописи: {prompt}. Фон {background}.",
  "inputs": [{"name": "background", "title": "Фон", "default": "тёмный", "required": false}],
  "params": {"size": "1024x1024"}
}
```

```sh
looma model add contract-translator --base Qwen3.8-Flash-Next-NVFP4 --preset preset.json
looma model set contract-translator --preset preset.json     # поправить настройку
```

Настройку можно править, пока она не опубликована. Опубликованную сначала снимают с
публикации: её содержимое проверяла площадка.

### Как вызвать настройку {#call}

Настройка вызывается по тому же API, что и её модель. Вместо сообщений можно прислать
поля входа в `input`, запрос соберётся по шаблону:

```sh
curl "$LOOMA_API_URL/chat/completions" -H "Authorization: Bearer $LOOMA_APP_TOKEN" \
  -d '{"model": "anna/contract-translator", "input": {"text": "Договор подряда"}}'
```

```python
from loomafloat import Looma

text = Looma().chat("anna/contract-translator", input={"text": "Договор подряда"})
```

Обычные `messages` тоже принимаются: системный промпт настройки встаёт перед ними.
Настройка изображений и видео принимает `prompt` и `input` на адресах `/v1/images` и
`/v1/videos`. Параметр, который прислал вызывающий, сильнее закреплённого.

Тем, кто вызывает настройку, видны её поля входа, описание и цена. Системный промпт и
шаблон им не показываются. В поле `model` ответа стоит имя модели, которая считала.

В манифесте сервиса настройка объявляется как любая модель:

```yaml
gpu:
  translate: { model: anna/contract-translator }
```

## Цена {#price}

Цена своей модели задаётся в рублях: за 1M входных и выходных токенов, за изображение
или за секунду видео, по виду модели. У модели на движке со своим API цена задаётся за
вызов: `--price call=1.5`. Без цены модель бесплатна.

```sh
looma model set qwen-legal --price in=5 --price out=12.5
looma model set contract-translator --price out=50
looma model set qwen-legal --free
```

Цену платит тот, кто вызывает модель. Свои вызовы автор не оплачивает. Из цены
вычитается комиссия площадки.

У настройки цена означает надбавку. Вызывающий платит за модель, поверх которой
сделана настройка, как при прямом вызове, и сверху надбавку автора настройки. В списке
моделей у настройки показана полная цена.

Начисления записываются в учёт площадки. Выплат пока нет.

## Публикация {#publish}

```sh
looma model publish qwen-legal       # на проверку площадки
looma model unpublish qwen-legal     # снять с публикации или отозвать заявку
```

До одобрения модель вызывает только автор. Площадка проверяет описание, цену и, у
настройки, её содержимое. При отказе причина видна в `looma model show` и в кабинете
автора: исправьте и подайте снова.

Настройка публикуется, если модель под ней доступна всем: это модель площадки или
опубликованная модель автора.

## Команды {#commands}

| Команда | Что делает |
|---|---|
| `looma model` | свои модели: вид, состояние, публикация, цена |
| `looma model show <имя>` | модель подробно; у настройки её содержимое |
| `looma model check --repo …` | проверить веса без запуска |
| `looma model add <имя> …` | добавить: `--repo`, `--base … --adapter …` или `--base … --preset …` |
| `looma model set <имя> …` | описание, цена, настройка, реплики |
| `looma model publish <имя>`, `unpublish <имя>` | публикация |
| `looma model delete <имя> --yes` | удалить модель |
| `looma model name [имя]` | имя автора |
| `looma model adapters` | адаптеры LoRA проекта |

Все флаги: [CLI](cli.md#own-models). Инструменты для ИИ-агента: [MCP-сервер](mcp.md).

Модель можно собрать и на движке другого автора или на своём: [Свой движок](engines.md).

## Только на своих узлах {#own-nodes}

Модель со своими репликами можно держать только на своих машинах. Узел подключается в
разделе «Узлы» кабинета автора; там же видно, какие движки на него встанут.

```sh
looma model add qwen-legal --repo anna/qwen-legal --own
looma model set qwen-legal --network        # разрешить и узлы сети
```

На своих узлах время видеокарт не записывается. Пока ни один ваш узел не на связи,
такая модель не отвечает: на узлы сети она не уходит.

## Что стоит знать {#limits}

- Удаление модели необратимо. Сервисы, которые её вызывают, начнут получать отказ.
  Настройки, сделанные поверх удалённой модели, перестают отвечать.
- Настройка делается поверх текстовой модели, модели изображений или видео. Поверх
  другой настройки она не делается.
- Формат ответа у настройки тот же, что у её модели.
- Несколько адаптеров на одной реплике пока не работают: каждая модель с адаптером
  держит свои реплики.
