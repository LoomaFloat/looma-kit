# Движки

Движок означает программу, которая держит модель на видеокарте и отвечает на запросы.
На Looma Float есть движки площадки, а свой движок может опубликовать автор. Здесь
лежит учебный движок и расширение к нему: с них удобно начать свой.

| Папка | Что это |
|---|---|
| [`echo`](echo/) | учебный движок: повторяет последнее сообщение. Без весов и без видеокарты, весь договор с площадкой в одном файле |
| [`echo-upper`](echo-upper/) | расширение учебного движка: делает ответ заглавными |

## Как устроен движок

В корне папки лежит `looma-engine.yaml`: имя, пакет с кодом, команда запуска,
зависимости, требования к узлу и поля, которые автор записи задаёт в форме. Рядом
пакет на Python, его площадка и доставит на узел.

Движок запускается одним процессом на одном узле и слушает порт из
`LOOMA_SERVE_PORT`. Что он должен уметь:

- `GET /health`: 200 и `{"status": "ok"}`, когда готов отвечать;
- `POST /v1/chat/completions` в формате OpenAI, со счётчиками `usage`.

Запустить у себя:

```bash
cd engines/echo
LOOMA_SERVE_PORT=8000 python -m echo_engine.server
```

```bash
curl http://127.0.0.1:8000/v1/chat/completions -d '{"messages":[{"role":"user","content":"привет"}]}'
```

## Как опубликовать

Движок публикуют из открытого репозитория на GitHub: называют репозиторий, коммит
целиком и папку. Площадка читает код, и после ревью движок можно ставить на узлы.

```bash
looma engine submit --repo https://github.com/вы/репозиторий --commit <коммит> --path engines/echo
looma engine list
```

Подробно: [Свой движок](https://docs.loomafloat.ru/authors/engines/).
